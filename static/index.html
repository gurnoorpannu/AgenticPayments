MandateGuard

Adversarial testing layer for agentic payments — AP2 / UAP-style signed mandates

A valid signature proves someone signed something. It does not prove the content being signed reflects what the user actually wanted. Everything upstream of signing — catalog data, tool results, inter-agent messages — is unsigned and manipulable.
