Adversarial testing for agentic payments

A valid signature proves someone signed something.
It does not prove they meant it.

AP2 and UAP secure agent-initiated purchases with signed mandates. Everything upstream of the signature — catalog data, tool results, the approval screen — is unsigned and manipulable. An attacker never forges a signature. They poison the context that decides what gets signed.

In the attack below, every signature verifies and every downstream check passes. There is no failed check to report, because nothing downstream is wrong — the closed mandate genuinely does fall inside the ceiling the user signed. The lie is in the premise, which is why verification alone structurally cannot catch it.
